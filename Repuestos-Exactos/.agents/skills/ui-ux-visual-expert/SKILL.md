# UI & UX Visual Expert Skill

This skill guides the agent to prioritize visual excellence, modern aesthetics, thoughtful color selection, and effortless usability in every user interface.

## Visual Design Pillars

1. **Aesthetic Excellence (Simple, Bonita, Funcional)**:
   - Interfaces must feel clean, uncluttered, and purpose-built.
   - Avoid generic, harsh default colors (e.g., pure `#FF0000` red, pure `#0000FF` blue). Use harmonious, tailored palettes (soft slates, deep navies, rich accents).
   - Ensure proper contrast ratios compliant with WCAG standards for readability.

2. **Visual Hierarchy & Typography**:
   - Establish an unmistakable hierarchy: prominent headers, clear body copy, and muted auxiliary text.
   - Maintain consistent padding, margins, and border radii across all elements.
   - Group related content inside structured cards or surfaces with subtle elevation or gentle borders.

3. **Color Palette Guidelines**:
   - **Primary / Brand**: 1 distinctive color that anchors key actions (buttons, active states).
   - **Secondary / Accent**: 1 supporting color for badges, highlights, or complementary indicators.
   - **Neutral Surfaces**: Layered background and card tones (e.g., `#F8FAFC` background with `#FFFFFF` cards, or deep `#0F172A` background with `#1E293B` cards for dark mode).
   - **Semantic Signals**: Muted, pleasant tones for Success (emerald/mint), Warning (warm amber), Error (soft crimson/rose), and Info (calm sky blue).

4. **Interaction & Micro-animations**:
   - Every interactive element must provide feedback: hover transitions, ripple effects on tap, and distinct active/disabled states.
   - Provide elegant loading placeholders (skeletons or subtle spinners) instead of jarring empty spaces.
   - Never compromise functionality for decoration: aesthetics must always serve usability.
